# agent-log

このフォルダは、AI（agent-runner）がこのリポジトリに入れた変更の記録です。1件1ファイルで、新しいものほど日付が新しいです。

別の AI がこのリポジトリを理解するときに読むことを想定しています。各ファイルは次の形です。

- 先頭の `---` で囲まれた部分は機械向けの要約です（date, repo, kind, source_url, files, model, run_url, pr_status）
- 「やったこと」「なぜ」「出典」は、選んだ時点の計画です
- 「変更したファイル」は実際の差分から機械的に書いたもので、正確です
- 「OpenCode の報告」は作業したモデル本人の申告で、人や CI が確かめたものではありません
- pr_status は書いた時点のものです。マージされたかどうかは git の履歴で確かめてください

人が PR を見て main に入れるかどうかを決めます。自動ではマージしません。
